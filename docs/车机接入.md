# 车机 MCP 方案（手机 Termux 宿主角 —— 已实测加固）

手机 Termux 同时承担 **MCP 服务端** 和 **adb 客户端** 两个角色，AI 客户端通过 `adb forward` 隧道接入，进而操作车机。

## 为什么 Termux 方案最优

| 维度 | 手机 Termux 宿主角 | PC 端 mobile-mcp |
|---|---|---|
| 车机兼容性 | ✅ 纯 adb shell，Buildroot 车机可用 | ❌ 依赖 uiautomator2/无障碍树，非 Android 车机无效 |
| 车机可达性 | ✅ 手机连车机热点即可，手机始终在场 | ❌ PC 必须与车机同网段 |
| 现场部署 | ✅ 手机+车机即可，无需 PC | ❌ 需 PC 参与 |
| 断线恢复 | ✅ 手机端守护自动重连 | ❌ 需 PC 端守护 |

车机 `.39` / `.133` 是 **Buildroot Linux**（无 `getprop`/`wm`），只有纯 shell 路线能操作 —— 这直接决定了 Termux 方案的胜出。

## 拓扑

```
AI 客户端 (PC, WorkBuddy)
   │  http://127.0.0.1:18081/mcp
   ↓  adb forward tcp:18081 → tcp:8081     ← tunnel-watch.sh 守护
手机 Termux
   ├─ termux-native-mcp v0.15.0  (:8081, 127.0.0.1)   ← car_watchdog.sh 守护
   └─ adb 客户端 (android-tools 37.0.0)
         ↓  adb connect <车机IP>:5555
      车机 (.39 / .133, Buildroot/wise, SStar SoC)
```

## 已安装的组件

### 手机端 `~/mcp-servers/car/`
| 文件 | 作用 |
|---|---|
| `car_watchdog.sh` | 主守护：拉起 MCP + 维护车机 adb 连接，20s 周期 |
| `boot_car_mcp.sh` | 开机自启入口，已放入 `~/.termux/boot/` |
| `cars.txt` | 车机清单（IP:PORT + 备注），改这里增删车机 |
| `car_setup.sh` | 手动连接车机 + 输出接入指引 |
| `scan_car.py` | 网段扫描找 5555 设备并自动 connect |

### PC 端
| 文件 | 作用 |
|---|---|
| `C:\Users\ZYH\tunnel-watch.sh` | 隧道守护，断线自动重建 forward |
| `C:\Users\ZYH\.workbuddy\mcp.json` | `phone-termux-mcp` → `http://127.0.0.1:18081/mcp` |

## 使用

```bash
# 手机 Termux 内
bash ~/mcp-servers/car/car_watchdog.sh start     # 启动守护
bash ~/mcp-servers/car/car_watchdog.sh status    # 看状态
bash ~/mcp-servers/car/car_watchdog.sh stop      # 停
python3 ~/mcp-servers/car/scan_car.py 192.168.110  # 扫车机

# PC 侧
bash ~/tunnel-watch.sh &                          # 隧道守护
bash ~/tunnel-watch.sh once                       # 只建一次
```

## 故障注入验证结果（均实测通过）

| 故障 | 表现 | 恢复 |
|---|---|---|
| 杀掉 `termux-native-mcp` | 8081 监听消失 | ✅ 守护 20s 内自动拉起 |
| 删除 adb forward | `forward --list` 消失该条 | ✅ 隧道守护 20s 内重建 |
| 车机 adb 掉线 | devices 中状态变 offline | ✅ `reconnect_cars` 自动 connect |

## 已知限制

- **8081 绑 127.0.0.1**，PC 直连 `192.168.110.13:8081` 会被 reset，必须走 forward 隧道
- **Termux 版 adb 无 `adb mdns`** → 车机 IP 必须手填或扫描
- **Termux 权限受限**：`ip` 报 netlink 权限错；`run-as com.termux` 不可用（非 debuggable）
- **无 Termux:API / 无 rish** → 开机自启需装 Termux:Boot APK；否则靠守护进程续命
- Windows Git Bash 下 `adb pull /sdcard/x` 会被 MSYS 路径转换破坏，需加 `MSYS_NO_PATHCONV=1`
- PC 侧 `adb` 不在 PATH，需 `export PATH="/e/QtScrcpy-win-x64-v4.2.1:$PATH"`

## 待办（需用户操作）

1. 安装 **Termux:Boot** APK → 开机自启生效
2. 若手机有车机热点场景，在 `cars.txt` 更新为热点网关 IP（如 `192.168.43.1:5555`）
